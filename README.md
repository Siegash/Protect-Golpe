ISSO É GOLPE? — protótipo inicial
=================================

Arquivos
- index.html: site completo em um único arquivo.
- README.txt: estas instruções.

Como abrir
1. Baixe e extraia o ZIP.
2. Abra index.html em um navegador atualizado.
3. Não precisa instalar nada nem criar conta.

O que funciona
- Interface responsiva para desktop e celular.
- Caixa de análise com detector demonstrativo baseado em regras e palavras-chave.
- Exemplos clicáveis para testar.
- Guias de segurança para golpes comuns.
- Orientações gerais para quem já foi vítima.

Limitações importantes
- A análise é educativa e NÃO confirma se uma mensagem é golpe.
- Não há conexão com inteligência artificial, banco de dados, API externa ou servidor.
- A análise acontece localmente no navegador; o texto não é enviado a um servidor por este protótipo.
- Não cole dados pessoais, senhas, códigos, documentos ou informações bancárias.
- Antes de lançar publicamente, revise o conteúdo, teste acessibilidade, inclua fontes oficiais atualizadas e peça revisão de segurança.
- Se adicionar IA no futuro, mantenha a chave de API no servidor (nunca no HTML) e estabeleça política clara de privacidade e retenção.

Próximas etapas sugeridas
1. Testar com pessoas do público-alvo.
2. Melhorar a análise com explicações e fontes verificáveis.
3. Se integrar IA, criar backend seguro, limites de uso, tratamento de erros e proteção de dados.
4. Validar juridicamente e em segurança as orientações de emergência.
